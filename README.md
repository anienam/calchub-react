# CalcHub 🧮

CalcHub is a multifunctional calculator application built with React and JavaScript. It brings together useful calculation tools in one responsive interface.

## Features

- **Scientific Calculator:** Perform scientific and mathematical calculations.
- **Unit Converter:** Convert between supported measurement units.
- **Grade Calculator:** Calculate academic grades.
- **Responsive Interface:** Designed for use across different screen sizes.
- **Reusable React Components:** Organised application logic and interface elements.

## Tech Stack

- React 19
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite 6

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/anienam/calchub-react.git
```

Navigate into the project:

```bash
cd calchub-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
